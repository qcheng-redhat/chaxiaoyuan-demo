How this version works

When a customer submits an order on the menu page, it is aggregated here in structured form, and the store works through orders by status.

Cloud mode (accessed via http/https): orders live on the server — open the dashboard on any device, enter the admin passcode, and see the same data. Auto-refreshes every 10 seconds.

Local demo mode (opened as a local file): orders are aggregated in the same browser — same features, but not shared across devices.

Where data is stored

Local storage key: chaxiaoyuan_orders_v1_en.
Leave ORDER_ENDPOINT empty in the menu page for demo mode; fill in a form submission URL to sync orders to the cloud.
